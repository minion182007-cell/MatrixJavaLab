# MatrixJavaLab

Практическая работа №1: класс для работы с матрицами комплексных чисел на Java.

## Возможности

- сложение матриц
- умножение матриц
- деление матриц (A / B = A · B⁻¹, если B обратима)
- транспонирование
- вычисление определителя (метод Гаусса)

Обратная матрица находится методом Гаусса–Жордана.

## Структура

| Класс | Назначение |
|---|---|
| `Complex` | комплексное число и арифметика над ним |
| `ComplexMatrix` | матрица комплексных чисел и операции над ней |
| `Main` | консольный интерфейс |

## Запуск

```
javac Main.java
java Main
```

## Использование

Программа просит ввести размеры матрицы A, затем её элементы. Каждый элемент вводится двумя числами: действительная и мнимая часть.

Пример ввода матрицы 2×2 `| 1+i  2 |  | 3  4-i |`:

```
Число строк: 2
Число столбцов: 2
[0][0] = 1 1
[0][1] = 2 0
[1][0] = 3 0
[1][1] = 4 -1
```

Дальше выбирается операция из меню:

```
1 - сложить A + B
2 - умножить A * B
3 - разделить A / B
4 - транспонировать A
5 - определитель A
0 - выход
```

Для этой матрицы определитель равен `-1.0+3.0i`.

При несовместимых размерах или нулевом определителе программа выводит сообщение об ошибке и продолжает работу.
